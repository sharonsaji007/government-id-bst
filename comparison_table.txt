BST SEARCH VS LINEAR SEARCH

Parameter              BST              Linear Search
-------------------------------------------------------
Best Case              O(1)             O(1)
Average Case           O(log n)         O(n)
Worst Case             O(n)             O(n)
Insertion Order Effect Yes              No
Extra Storage          O(n)             O(1)
Dynamic Data            Suitable         Suitable
Large Database         Balanced BST     Less efficient
